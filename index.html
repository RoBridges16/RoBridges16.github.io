# 01 - academic & technical projects

Projects

Optimising Network Flow: From Graph Theory to Real-World Systems

LaTeX Graph Theory Proof-writing

A self-directed report on flow networks, written and typeset in LaTeX. Builds up capacitated networks and cuts from first principles, then proves the Max-Flow Min-Cut theorem in full - by induction, following the trichotomy used in Ford & Fulkerson's original 1956 paper. The proof is then put to work on two concrete problems: lane-closure planning for London–Durham motorway traffic, and bandwidth allocation across a data network, in each case using the minimum cut to bound achievable throughput.

Computational Geometry & Ray-Tracing

Python Matplotlib Computational Geometry

A geometry engine built from scratch across thirteen staged tasks: line and segment intersection from first-principles linear algebra, ray casting against a bounded window, reflection vectors off arbitrary mirror segments, nearest-intersection search across a scene, and periodic boundary wrapping so a ray that exits one edge re-enters the opposite one.
